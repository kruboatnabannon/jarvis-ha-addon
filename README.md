# 🤖 J.A.R.V.I.S. Home Assistant Add-on Repository

Repository สำหรับติดตั้ง **J.A.R.V.I.S. (จาวิส)** ผู้ช่วย AI อัจฉริยะส่วนตัวรอบด้าน เข้าสู่ **Home Assistant OS**

---

## 🚀 วิธีติดตั้งลง Home Assistant (1-Click Install)

1. เปิดหน้าเว็บ **Home Assistant** ของคุณ
2. ไปที่ **Settings (การตั้งค่า) → Add-ons (ส่วนเสริม) → Add-on Store (ที่มุมขวาล่าง)**
3. กดปุ่มจุดสามจุดมุมบนขวา `...` แล้วเลือก **Repositories (ที่เก็บส่วนเสริม)**
4. นำ URL ของ Repository นี้ไปวาง:
   ```
   https://github.com/kruboatnabannon/jarvis-ha-addon
   ```
5. กด **Add (เพิ่ม)**
6. เลื่อนดูรายการจะพบ **J.A.R.V.I.S. Brain Core** ขึ้นมาให้กด **Install** ได้ทันที!
